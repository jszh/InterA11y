Riverport Metro — System Map

Riverport Metro runs four lines across the city. Use the map to plan your journey; a text description of the network follows below it.

Network description

The Riverport Metro has four lines. The Red line runs east–west between Westgate and Harbourside. The Blue line runs from Northvale in the north-west down to Old Mill in the south-east. The Green line runs north–south between Meadow and Quayford. The Yellow line is a southern loop serving the riverside districts. Trains run every four to six minutes during peak hours.

Fares are zone-based. Contactless payment is accepted at every gate.
