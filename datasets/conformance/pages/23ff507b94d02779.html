منصة سحابة نون — مرجع الـ API

نقطة النهاية: قائمة الطلبات

GET /v2/orders

يعيد هذا الطلب صفحة من الطلبات. استخدم المعامل cursor المؤشر (cursor) قيمة معتمة تشير إلى موضعك في النتائج. مرّره دون تعديل إلى الطلب التالي للحصول على الصفحة التالية؛ تنتهي صلاحيته بعد ٢٤ ساعة. للتنقل بين الصفحات. كل صفحة تحتوي على ٥٠ عنصرًا افتراضيًا. 

curl https://api.noon.cloud/v2/orders?cursor=eyJpZCI6 \
  -H "Authorization: Bearer $TOKEN"

يظهر التلميح عند تمرير المؤشر فوق كلمة "cursor" ويغطي مثال الطلب أدناه. معالج Escape موجود لكنه يتحقق أولاً من وجود عنصر إدخال مركّز عليه؛ وعند تمرير المؤشر فوق الكلمة لا يوجد أي عنصر مركّز، لذا فإن Escape لا يفعل شيئًا. (Esc is gated on an input being focused; on hover nothing is focused, so it is inert.)
